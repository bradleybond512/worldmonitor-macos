## Adding a panel

1. Implement a `Panel` subclass in `src/components/`.
2. Register it in the appropriate variant array (`FULL_PANELS`, `TECH_PANELS`, etc.) inside `src/config/panels.ts`.
3. Add the panel ID to `PANEL_CATEGORY_MAP` so it appears in the sidebar.
4. Add a sidecar route in `src-tauri/sidecar/local-api-server.mjs` or `api/*.js` if it needs a server-side data source.
5. Add the new IDs to any necessary tests under `tests/`.
6. Update this file with the panel's category and a one-line description.
